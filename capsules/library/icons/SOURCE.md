# Explorer Icon Assets

These SVG assets are copied from the PC2 reference repo to preserve Explorer
visual parity while the Runtime implementation stays on typed provider rails.

- Source repo: `Elacity/pc2.net`
- Source baseline: `main` at `a0a910158bd67666a6d3ea2a775ce09005ba7ae7`
- Source path: `src/gui/src/icons/`

Only static icon assets are mirrored here. PC2 runtime modules, Puter authority
logic, generated bundles, direct IPFS/Kubo calls, and filesystem shortcuts are
not imported into ElastOS Runtime.
