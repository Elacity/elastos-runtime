`assistant` capsule. Home owns its shelf motion and frame. Assistant owns
conversations, drafts and typed model controls; Runtime owns storage and model

their protected objects in place. Unknown fields, complete text, roles, projects,
drafts and attachments survive adoption. Old writers receive an explicit
conflict after adoption. Imported foreign runs keep their original actor and IDs;

retains an unknown result when a create response is lost. Each session owns its
run cursor and complete output history. Reload reads the same run; opening or
switching modes creates no run. Chat and Studio keep separate drafts. An absent
image/video offer produces the existing unavailable state.
