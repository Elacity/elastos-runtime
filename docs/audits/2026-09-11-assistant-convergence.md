# One Assistant: preservation and installed proof

The approved C3 slice puts Sash’s Agent Space and composer in the canonical
`assistant` capsule. Home owns its shelf motion and frame. Assistant owns
conversations, drafts and typed model controls; Runtime owns storage and model
authority. Existing URUX/UIUX history remains integrated. This slice does not
change J1–J5 or D1–D6, publish another branch, or deploy the public Home.

Migration retains immutable raw copies of the three original stores and leaves
their protected objects in place. Unknown fields, complete text, roles, projects,
drafts and attachments survive adoption. Old writers receive an explicit
conflict after adoption. Imported foreign runs keep their original actor and IDs;
the new Assistant shows unknown outcomes without taking ownership of those runs.

Studio saves a request ID before dispatch, blocks duplicate submissions and
retains an unknown result when a create response is lost. Each session owns its
run cursor and complete output history. Reload reads the same run; opening or
switching modes creates no run. Chat and Studio keep separate drafts. An absent
image/video offer produces the existing unavailable state.

## Review and failure disposition

Independent review covered the initial storage/import contract, source
preservation, active-run conflict races, launch retirement and installation
receipts. Repairs include fail-closed hydration, merge guards before and after
network waits, durable save acknowledgment, historical actor ownership and
retired launch generations.

The first storage isolation failure came from a test fixture that reused the
same passkey. Distinct credentials now prove distinct principals. The first
rendered Unicode failure came from the fixture decoding each HTTP chunk
separately; whole-body UTF-8 decoding preserves exact text. A product sidebar
path bypassed draft restoration and was routed through the shared selector.
Explicit New Chat after an unknown run retains the unsent draft in both histories.
Diagnostics and exact source/build/process receipts stay in the private operator
checkpoint. The Mac Runtime build passes; providers, engine and model data are
reused. Linux remains pending on its recorded capacity and startup-profile gates.

Final packaging/signing follows source freeze and the release gate. Human
recovery acceptance, cold Carrier delivery, remaining contributor integration,
Browser and protected-content gates retain their existing status.
