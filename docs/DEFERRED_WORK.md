# Deferred and future work

The [dated backlog snapshot](audits/2026-09-23-open-backlog-snapshot.md)
preserves earlier open follow-up. It is a record for later triage, not a second
execution queue. [GitHub issues](https://github.com/Elacity/elastos-runtime/issues) own the work queue and verified facts; an item
starts only when it has an issue with an owner, target and next proof.

## Retained source integration

Carrier framing limits, native-component interoperability and advanced Assistant workflows need a current-contract review before implementation. The [snapshot](audits/2026-09-23-open-backlog-snapshot.md#retained-source-integration) keeps their detailed clauses.

## Collaboration identity and Carrier boundary

Offline mailbox delivery, attachments, multi-device pairing, user-created groups and wider discovery are outside the current J6 Chat journey. J6 CH5 still requires bounded public-room history and catch-up; general group catch-up remains later. The [snapshot](audits/2026-09-23-open-backlog-snapshot.md#collaboration-identity-and-carrier-boundary) keeps the later clauses; the [collaboration handoff](COLLABORATION_HANDOFF.md) defines the current two-Home acceptance.

## Collaboration and messaging

Later People/Services separation and IRC packaging remain follow-up work. The [snapshot](audits/2026-09-23-open-backlog-snapshot.md#collaboration-and-messaging) retains their criteria.

## Other future work

The snapshot also preserves Browser expansion, Component/Bus, WebSpace, storage markets, documents, Inbox, operator hardening and long-term proposals. None has an active target lease from this index. The 0.7.1 release plan remains the authority for any item it marks Required.
