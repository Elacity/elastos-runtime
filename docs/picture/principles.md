# Teach from this

Law is `PRINCIPLES.md` on `review/collaboration-candidate` (`b07160c`).

1. The product starts at the person's Home. Objects are `localhost://` names, not host paths or cloud accounts.

2. A capsule should ask Runtime for an effect and not pick a pipe. That is the law. On this SHA a browser capsule still sets `webrtc_remote_display`. Same-node authenticated loopback is not in this tree. Local work is not required to wear a Carrier envelope.

3. Home is `elastos gateway` (or `elastos home`). Seed / `elastos serve` is the operator lane.

4. ESP is the shell protocol. It is not Carrier. Bus is how components invoke.

5. The content encryption key must not show up in an app. Decrypt and license go through a provider. The glossary describes dKMS as key release. The principles allow local storage, Carrier, or another substrate. Carrier-only is the product rule we are holding, not a sentence in that glossary.

6. HTTP `/api/provider` is not the capsule contract. It is still live. Library, wallet, and System still call it. Old chat and agent gossip drawings are stale. Product Chat is chat-room. `elastos chat` / `elastos agent` are leftover CLI, not installable capsules.

Apps people ship are still web projections, not Components.
