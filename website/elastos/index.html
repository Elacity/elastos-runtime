Set up Home from source

Build a reviewed checkout and install it into a separate test Home. This takes developer tools and time for the first build.

Mac setup guide +

This guide follows upstream/0.7.1-dev at 6c61c990. It prepares a local source build; its version is separate from the Home served by this website.

1. Prepare the Mac

Use Apple silicon with Xcode command-line tools, Homebrew, Git and Rust. Follow the Mac runbook for the prerequisite installs. Keep at least 10% of the disk free for builds.

2. Get the source

Create a local branch at the reviewed commit. The final command prints the source identity for your test record.

git clone --branch upstream/0.7.1-dev --single-branch https://github.com/Elacity/elastos-runtime.git
cd elastos-runtime
git switch --create feat/local-home-preview 6c61c990b9a1d0f2c1b00ee6f5f091d3354cafac
git rev-parse HEAD

3. Build a separate test Home

From the checkout, keep Rust on your normal toolchain and install the test Runtime into its own data home.

export MAC_TEST_HOME="$HOME/elastos-mac-test-home"
export ELASTOS_OPERATOR_HOME="$HOME"

HOME="$MAC_TEST_HOME" \
CARGO_HOME="$ELASTOS_OPERATOR_HOME/.cargo" \
RUSTUP_HOME="$ELASTOS_OPERATOR_HOME/.rustup" \
PATH="$ELASTOS_OPERATOR_HOME/.cargo/bin:/opt/homebrew/bin:$PATH" \
scripts/setup-source-home.sh

4. Start and check Home

The restart helper checks the installed files and prepares the data roots. Use the Home address it prints. Keep the same hostname for passkey sign-in.

scripts/mac-source-home-restart.sh \
  --init \
  --test-home "$MAC_TEST_HOME" \
  --addr localhost:61180

curl -fsS http://localhost:61180/api/health

Home and passkeys can be tested before the Browser VM is ready. The Mac runbook has the extra Browser steps, restart checks and shutdown guidance.
