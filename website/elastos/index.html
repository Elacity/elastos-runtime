How it fits together

What ElastOS is

01 /

Runtime

The software that runs on your machine. It manages apps, services and access to your data.

02 /

Home

Your desktop in the browser. Sign in with a passkey to open apps and manage your account.

03 /

Apps

Web apps for tasks such as writing, managing files and connecting with people. A source package becomes a signed capsule only after complete packaging and signing. Your documents and settings stay separate from the installed app.

04 /

Permissions

Reading a document, changing it and sharing it each need permission. Runtime checks access for apps and AI agents alike.

Current boundary

Isolation status

This describes the source boundary after the required changes pass integration. Apps run as web projections in the browser's opaque sandboxed frames. Runtime checks their capability tokens. Home can currently obtain every app's capability. The target limits Home to delegation and gives each app a separate, revocable capability.

Providers

Providers run as operating-system processes. Only the model provider is partly confined. A provider manifest alone does not prove host isolation. If an owner enables the web Terminal, it runs commands as the host user through a host process.

Data and keys

Keys are stored next to the data they protect. Full backups contain all keys. The seed operator can read data, wallet keys and recovery phrases stored on the seed.

Recovery

Recovery from a stolen device or profile key requires a new identity. Keep your Recovery Kit under your own control.

Proof

These source guarantees require the content sandbox, front-door and disabled-terminal changes to be integrated and tested together. Accepted installed proof binds the exact Runtime, components and app assets to tested journeys on that device.
