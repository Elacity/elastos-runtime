# ElastOS Runtime roadmap

GitHub issues own scope, order, status and acceptance. This page links planned
outcomes; it does not assign work or set release dates.
[Principles](PRINCIPLES.md) and [Architecture](docs/ARCHITECTURE.md) define the
constraints and responsibility boundaries.
